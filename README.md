# Beyond Data: siting tool (public web version)

A tool for siting small data centres in cities as good neighbours: what fits on a lot, what heat it could share, and who nearby could use it. Vancouver and Edmonton.

This repository holds only the built public site (the `site` folder). Every file's source and licence is listed in the site's manifest and on its Sources page.
